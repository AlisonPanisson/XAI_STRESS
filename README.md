# Explainable AI for Stress Identification

This repository contains exploratory notebooks and datasets for stress classification using physiological signals. It also includes a reproducible WESAD evaluation script with subject-independent and subject-specific validation.

## Project Contents

- [Stress identification notebook](XAI%20to%20Stresss%20Identification/analysis.ipynb): decision trees, random forests, feature importance, SHAP, LIME, and XGBoost experiments.
- [Feature dataset](XAI%20to%20Stresss%20Identification/rawdata.csv): engineered HR, temperature, and EDA features with a binary `Stress` target. This CSV is used by the exploratory notebook, not by `rerun_wesad.py`.
- [WESAD analysis notebook](WESAD/analysiswesad.ipynb) and [algorithm comparison table](WESAD/table.md): earlier preprocessing and modeling experiments.
- [WESAD evaluation runner](rerun_wesad.py): corrected windowing, cross-validation, tuning, and reporting workflow.
- [Multiclass results](results/summary.md) and [binary results](results_binary/summary.md): reports generated by the runner on the WESAD dataset.

## WESAD Evaluation

The runner uses wrist EDA and temperature from each subject's pickle file, heart rate from the Empatica E4 `HR.csv`, and labels from the pickle file. It creates 60-second windows at 30-second intervals without crossing label boundaries. Subject S1 and S12 are excluded; the default run uses S2-S11 and S13-S17.

The default evaluation includes:

- Leave-one-subject-out (LOSO) evaluation for generalization to unseen subjects.
- Subject-specific blocked cross-validation with a purge gap to avoid overlap leakage.
- Static classifiers (kNN, logistic regression, random forest, SVM, and neural network) and time-series classifiers (Time Series Forest and ROCKET).
- Training-fold-only scaling, inner-fold hyperparameter tuning, per-subject metrics, paired statistical tests with Holm correction, a random-split leakage diagnostic, a calibration curve, and a separate VAR forecasting analysis.

## Setup

Install the required Python packages:

```bash
python -m pip install numpy pandas scipy scikit-learn joblib
```

The script uses its in-script ROCKET implementation if `aeon` or `sktime` is not installed.

Obtain WESAD from the [Kaggle dataset page](https://www.kaggle.com/datasets/orvile/wesad-wearable-stress-affect-detection-dataset) or the original dataset source. The data files are not included in this repository. The directory passed to `--root` should contain subject folders in this form:

```text
WESAD/
    S2/
        S2.pkl
        S2_E4_Data/
            HR.csv
            EDA.csv
    S3/
        S3.pkl
        S3_E4_Data/
            HR.csv
            EDA.csv
```

The E4 files may also be inside a subject's `S*_E4_Data.zip` archive. The runner requires `HR.csv`; `EDA.csv` is optional and is used to align the heart-rate signal when available.

## Run

Run the multiclass task (baseline, stress, amusement, and meditation):

```bash
python rerun_wesad.py --root /path/to/WESAD --out results
```

Run the binary task (stress versus non-stress):

```bash
python rerun_wesad.py --root /path/to/WESAD --out results_binary --task binary
```

Run a synthetic smoke test without downloading WESAD:

```bash
python rerun_wesad.py --selftest
```

Useful options include `--no-tune` to skip hyperparameter search, `--no-ts` to skip time-series classifiers, `--skip-var` to skip forecasting, `--smote 1` to enable in-fold SMOTE, and `--quick` to reduce time-series model sizes.

## Output Files

Each output directory contains `summary.md`, per-subject CSVs for LOSO and blocked evaluation, window counts, the random-split diagnostic, calibration results, statistical tests, VAR forecasts, and `run_info.json` with the run configuration.
